5. Calibration Equation

Normalized point: x = X/Z, y = Y/Z, r² = x² + y² 

x_d = x(1 + k1 r² + k2 r⁴ + k3 r⁶) + 2 p1 x y + p2(r² + 2x²)
y_d = y(1 + k1 r² + k2 r⁴ + k3 r⁶) + p1(r² + 2y²) + 2 p2 x y
u_d = fx x_d + cx,   v_d = fy y_d + cy

The button computes a remapping table and samples the raw image so that straight camera rays become straight image geometry.
